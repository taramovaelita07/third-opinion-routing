# Сценарная валидация контура маршрутизации

Дата проверки: 4 октября 2026 года.

## Что проверяется

Проверка воспроизводит обработку уже готового структурированного результата
внешнего ИИ лучевой диагностики:

`DICOMREPORTNOTIFY → parsing → normalized findings → routing → Safety Layer`.

Она подтверждает корректность интеграционного и маршрутизационного контура.
Проверка **не измеряет диагностическую точность анализа изображений** и
**не является клиническим исследованием**. Все входные данные синтетические,
не содержат персональных данных и предназначены только для демонстрации.

## Методика

Для каждого сценария заранее зафиксированы ожидаемые:

- правило маршрутизации;
- приоритет;
- специальность;
- срок следующего шага;
- решение Safety Layer;
- возможность использования черновика маршрута.

Один и тот же код запускает полный pipeline и сравнивает фактический результат
с этими ожиданиями. Во всех сценариях уведомление пациента запрещено до
явного подтверждения врача.

Результат контрольного прогона: **4/4 сценария пройдены**.

## Воспроизведение

Windows PowerShell из корня проекта:

```powershell
cd backend
.\.venv\Scripts\python.exe -m scripts.validate_scenarios
```

Ожидаемая итоговая строка:

```text
Scenario validation: 4/4 passed
```

Полный набор регрессионных тестов:

```powershell
.\.venv\Scripts\python.exe -m pytest -q
```

## Интерпретация результата

Проверка показывает, что система:

1. формирует разные маршруты для разных модальностей и находок;
2. повышает приоритет при критическом признаке;
3. не скрывает исходное правило и доказательства;
4. блокирует продолжение при противоречивых данных;
5. сохраняет врача обязательным участником принятия решения.

Для заявления о клинической эффективности диагностического ИИ отдельно
потребуются размеченная выборка изображений, эталонные заключения специалистов,
заранее определённые метрики и клиническая валидация. Эти задачи находятся за
границами текущего hackathon MVP.

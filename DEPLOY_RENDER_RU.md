# Публичное размещение «Третьего мнения» на Render

Render собирает приложение из `Dockerfile` и выдаёт постоянный HTTPS-адрес
вида `https://third-opinion-routing-xxxx.onrender.com`.

## Что понадобится

- аккаунт GitHub;
- бесплатный аккаунт Render;
- репозиторий GitHub с содержимым этого проекта.

В репозиторий нужно загрузить именно содержимое корневой папки проекта. Файлы
`Dockerfile`, `render.yaml`, `compose.yaml` и папки `backend`, `frontend`, `data`
должны находиться на верхнем уровне репозитория.

## Создание сервиса

1. Войти на <https://dashboard.render.com/> через GitHub.
2. Нажать **New +** → **Blueprint**.
3. Подключить репозиторий проекта.
4. Убедиться, что Render нашёл файл `render.yaml`.
5. Нажать **Apply** и дождаться статуса **Live**.

Первая сборка Docker-образа может занять несколько минут.

## Проверка публичного адреса

Заменить `<PUBLIC_URL>` на адрес, который покажет Render:

- кабинет врача: `<PUBLIC_URL>/`;
- кабинет пациента: `<PUBLIC_URL>/patient`;
- проверка сервера: `<PUBLIC_URL>/health`;
- Swagger: `<PUBLIC_URL>/docs`.

На странице `/health` должна быть версия `1.4.0`.

Проверить ссылку в режиме инкогнито или на телефоне с мобильным интернетом.
Это подтверждает, что адрес доступен не только на компьютере разработчика.

## Ограничения бесплатного размещения

- Сервис засыпает после периода без входящих запросов; первое открытие после
  этого может занять около минуты.
- Локальная SQLite-база является временной и может очищаться при перезапуске
  сервиса. Для демонстрации используются только синтетические данные.
- Перед выступлением открыть публичную ссылку за 5–10 минут и выполнить
  **Сбросить демо**.

Локальный Docker-запуск остаётся резервным вариантом и не зависит от Render.

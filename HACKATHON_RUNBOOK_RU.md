# Третье мнение — памятка для демонстрации

Эта памятка позволяет запустить и показать прототип без истории переписки.
Проект использует только синтетические данные. Реальные сведения пациентов
загружать нельзя.

## 1. Обычный запуск

1. Открыть Docker Desktop и дождаться статуса **Engine running**.
2. Открыть папку проекта в VS Code.
3. Открыть Terminal → New Terminal.
4. Выполнить из корня проекта:

```powershell
docker compose up --build
```

Не закрывать терминал во время демонстрации.

## 2. Адреса

- Кабинет врача: <http://localhost:8000/>
- Кабинет пациента: <http://localhost:8000/patient>
- Swagger: <http://localhost:8000/docs>
- Проверка сервера: <http://localhost:8000/health>

Если браузер показывает старую версию, нажать `Ctrl + F5`.

## 3. Сценарий показа жюри

1. В кабинете врача нажать **Сбросить демо** и подтвердить сброс.
2. Выбрать **КТ** и сценарий с узлом лёгкого.
3. Нажать **Запустить анализ**.
4. Показать находку, рекомендованный маршрут, Safety Layer и цепочку
   прослеживаемости решения.
5. Развернуть исходный текст результата ИИ.
6. Подтвердить рекомендованную маршрутизацию.
7. Перейти кнопкой **Кабинет пациента**.
8. Показать уведомление и медицинскую карту.
9. Выбрать дату и время и подтвердить запись.
10. Вернуться кнопкой **Кабинет врача** и показать статус
    **Пациент записался**.

Врач подтверждает только медицинский маршрут. Дату и время выбирает пациент.

## 4. Завершение работы

В терминале с запущенным приложением нажать `Ctrl + C`, затем выполнить:

```powershell
docker compose down
```

История сохраняется в Docker volume и остаётся после обычного перезапуска.

## 5. Быстрое восстановление

### Сайт не открывается

Проверить, что Docker Desktop запущен, затем снова выполнить:

```powershell
docker compose up --build
```

### Порт 8000 занят

Остановить предыдущий запуск сочетанием `Ctrl + C`, затем:

```powershell
docker compose down
docker compose up --build
```

### Видна старая версия интерфейса

На нужной странице нажать `Ctrl + F5`.

### Нужно повторить показ

В кабинете врача нажать **Сбросить демо**. Эта кнопка очищает только
синтетические исследования, маршруты и демонстрационные записи.

### Нужно проверить проект перед выступлением

```powershell
cd backend
.\.venv\Scripts\python.exe -m pytest -q
cd ..
```

Ожидаемый результат финальной сборки: все тесты пройдены.

## 6. Контроль перед защитой

- Docker Desktop запущен.
- Оба кабинета открываются.
- Переключатель кабинетов виден.
- Сброс демо работает.
- КТ-сценарий запускается.
- Врачебное подтверждение доступно.
- Пациент видит маршрут и свободные интервалы.
- Запись пациента меняет статус у врача.
- Swagger открывается.
- Презентация и резервные скриншоты находятся рядом.
